# Kid Sticker GIF Series

A reusable workflow for building a consistent character model and producing expressive, single-sticker animated GIFs.

## Scope
- Character prototype creation from authorized references.
- Character model-sheet approval and continuity.
- Notion visual-style translation (S36/S37/S38).
- HRBP animation-reference analysis.
- Expression storyboarding and frame generation.
- GIF assembly, transparency, loop, and frame QA.
- Public/private asset separation.

## Core rule
**One expression = one independent GIF.** Sprite sheets and contact sheets are internal production or QA assets only.

## Files
- SKILL.md — complete production workflow and mandatory gates.
- references/notion-style-translation.md — implementation notes for S36/S37/S38.
- references/animation-reference-catalog.md — generic HRBP animation references.
- references/gif-technical-qa.md — assembly and technical QA.
- assets/hrbp-reference/ — generic HRBP motion examples only.

## Privacy
This public package excludes child photos, child-derived character anchors, company values, company names, logos, slogans, and company-specific reference assets. Those remain in a separate private asset collection.
