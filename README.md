# Prompt Architect | Master Hub by Lunabella

> 让每一个普通人，都能写出工业级稳定的 Prompt。

## 为什么做这个

在尝试把 AI 变成数字同事的过程中，最难的往往是把真实需求表达清楚。这个项目帮助用户完善指令、适配模型表达，并把验证有效的 Prompt 与工作流沉淀为可复用资产。

## 核心能力

- 指令体检：识别模糊描述与缺失上下文。
- 模型适配：为不同模型整理适配后的指令表达。
- 指令资产沉淀：将有效 Prompt、工作流和 AI Skill 保存为可复用资产。

## Reusable Skills

- [Kid Sticker GIF Series](skills/kid-sticker-gif-series/README.md)：从角色原型、角色一致性到单张动态 GIF 制作与逐帧验收的通用工作流。

本 Skill 的公开版本只包含通用方法和无品牌 HRBP 动画参考。儿童角色母版、儿童照片及公司价值观/品牌相关参考均保存在独立私有资产区，不进入本仓库。
